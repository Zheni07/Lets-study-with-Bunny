#  Да учим с Бъни (Lets Study with Bunny)

Уеб базирана образователна платформа, създадена с цел подпомагане на деца с дислексия чрез интерактивни игри и достъпно съдържание.

##  Изтегляне на проекта
Можете да изтеглите проекта от GitHub:

---

##  Стартиране на проекта локално

Следвайте стъпките по-долу, за да стартирате проекта на локална машина:

### 1. Клониране на проекта
```bash
git clone https://github.com/Zheni07/Lets-study-with-Bunny.git

2. Влизане в папката на бекенда
Навигирайте до директорията, в която се намира сървърната част на проекта.
Lets-study-with-Bunny> cd backend

3. Инсталиране на зависимости
npm install

4. Стартиране на бекенда
npm run dev

5. Стартиране на фронтенда
Отворете нов терминал и изпълнете:
node serve-frontend.js

6. Отваряне на приложението

След стартиране в терминала ще се появи линк.
Използвайте Ctrl + Click върху първия линк, за да отворите приложението в браузъра.
